# 声音风格卡（Voice Style Card）

> 旁白"怎么读"的决策表：场景 → {语速, 情感, 音色倾向}。与口味卡（prompt-styles.md）同哲学——
> 骨架管"想得对"（不踩声调雷），细节由渠道能力落地（`media_gen.py tts --emotion/--voice`）。
> 逐句参数写进 `vo_lines.json` 的 `voice` / `emotion` / `speed` 字段，省略则用全局默认。

## 一、场景 → 声音参数（默认组合，可逐句覆盖）

| 场景类型（shot 的 dramatic_function） | 情感 | 语速 | 音色倾向 | 说明 |
|---|---|---|---|---|
| 宣传片/卖点片（开场钩子、高潮落版） | 激昂 / 自豪 | 1.05-1.15 | 男声偏低沉（alex 类）或女声利落 | 短句、重音放动词；勿整片激昂（疲劳） |
| 科普/解说/教程 | 平稳 / 认真 | 0.95-1.0 | 中性偏清晰 | 每句一知识点；停顿比语速更显专业 |
| 情感独白/回忆/公益煽情 | 温柔 / 感伤 | 0.85-0.95 | 女声柔和或男声厚实 | 留白 40-50% 最合适；句间 `[停顿]` |
| 产品介绍/功能罗列 | 明快 / 自信 | 1.0-1.1 | 女声亲切或男声专业 | 术语前小停顿；数字念准 |
| 对话/采访/双声部 | 自然 / 俏皮 | 0.95-1.05 | 换两个音色交替 | 每句 voice 不同，模拟对谈 |
| 悬念/悬疑转场 | 严肃 / 低沉 | 0.85-0.95 | 男声低沉 | 关键词前停顿拉长 |

## 二、情感词表（`--emotion` / vo_lines 的 `emotion` 字段）

CosyVoice 系对中文情感词理解最好，直接用中文词即可；实测不明显的再上官方标记（`[laughter]` 等，见硅基流动文档）：

- **基本盘**：高兴 / 悲伤 / 激昂 / 温柔 / 平稳 / 俏皮 / 严肃 / 沉稳 / 紧张 / 自豪
- **进阶**：感伤 / 期待 / 惊讶 / 疲惫 / 坚定 / 亲切
- **官方标记**（写在文本里原样透传）：`[laughter]` 笑、`[whisper]` 耳语、`[pause]` 停顿——实测为准则，不必全用
- 情感是**引导不是强制**：CosyVoice 把"你能用高兴的情感说吗，"拼进正文（`_tts_emotion_prefix` 自动拼，零手写）；对当前句子生效，下一句无 emotion 自动回落

## 三、音色（`--voice` / vo_lines 的 `voice`）

- **硅基流动预置**：`FunAudioLLM/CosyVoice2-0.5B:alex`（官方示例音色）——完整列表以硅基流动控制台/文档为准；**想换预置名 = 改 env `MEDIA_TTS_1_VOICE` 一次，全局生效**
- **自定义音色**：硅基流动控制台上传参考音频 → 得到 `speech:<name>:<id>:...` 格式 → 填入 `voice`（逐句可换，如"这段用我的音色，那段用预置"）
- **男声/女声**：预置音色名带性别倾向（alex≈男）；要女主播就换预置女声名或传女声参考音频。**别在 prompt 里写"男声说"**——音色是 voice 参数的事，不是文本的事
- **降级自动换音色**：TTS 多 key failover 时音色跟随 key——硅基挂 → 自动切 Edge 女声（`MEDIA_TTS_2_VOICE`），**情绪也跟着没了**（Edge 无情感），此时脚本仍会出片，但成片前 agent 应提醒用户"当前降级到 Edge 兜底音色"

## 四、完整示例（vo_lines.json）

```json
{
  "total": 55.94,
  "lines": [
    {"id": "L01", "text": "清晨的徽州，从一场雾开始。", "emotion": "温柔", "speed": 0.9},
    {"id": "L02", "text": "千年文房，笔底波澜。", "emotion": "激昂", "speed": 1.1},
    {"id": "L03", "text": "这是我们的新起点，也是你的。", "voice": "FunAudioLLM/CosyVoice2-0.5B:alex", "emotion": "自豪"}
  ]
}
```

## 五、什么时候用风格卡

Step 2 分镜写 `dramatic_function` 时就定每句的声音参数（不写 = 全片默认平稳，损失情绪起伏）；
Step 3 写 VO 稿时把情感词直接写进 `emotion` 字段；Step 6 `vo_build` 自动落地，零手工。
